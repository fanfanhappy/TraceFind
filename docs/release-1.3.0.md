# TraceFind 1.3.0

让结果"可解释"：知道为什么没找到、知道某条为什么出现，语义结果也不会打断你手上的操作。

## 新增

- **无结果给下一步**：区分「还在索引」「正文索引关闭」「当前范围过窄」三种已知状态，各给一个对应操作；判断不出原因时只给通用建议，不猜
- **来源标签**：正文命中和语义命中会在文件名前标「正文」「语义」，标题里没有关键词的文档也能看出是哪来的
- **语义结果轻提示**：异步补入时列表顶部出现「新增 N 条相关结果」，可点击跳转；选中项按路径保持在原处
- **唤起续接**：重新唤起时恢复上次的选中项与滚动位置，不再是回到第一条

## 改进

- 空白页新增「添加文件夹」入口；索引为空时同时给出「添加文件夹」与「开始建立索引」
- 无结果页可一键「搜索全部目录」或「开启正文索引」

## 说明

索引结构与数据格式未变，直接替换 exe。语义提示只在使用向量检索时出现。
