# TraceFind 2.2.1

修预览的键盘交互：空格终于是预览键了。

## 修复

- **空格开/关预览**：在搜索框里直接按 `Space` 就能预览，不再需要先把焦点挪到结果上
- **Shift+Space 输入空格**：多词查询（如「预算 报告」）仍然可以打空格
- **中文输入不受影响**：输入法组合期间不拦截空格
- **结果区焦点**：方向键或点击后焦点在列表，继续打字会自动切回搜索框；Esc 关预览后焦点回到列表
- **预览内不误触**：焦点在预览里时只响应 Esc

## 说明

底栏一直写着「Space 预览」，之前其实只在焦点落到结果区时生效——这次把行为和提示对齐了。索引、更新、数据格式均未变化。
