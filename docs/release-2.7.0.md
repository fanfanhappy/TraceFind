# TraceFind 2.7.0

把托盘菜单从系统原生弹出菜单换成了应用自己的面板。

## 改动

- **自绘面板**：深色圆角、分组、图标、悬停高亮，跟主界面同一套视觉；不再是一排系统灰字
- **顶部信息**：文件名数（如「11 个文件」）与当前唤起快捷键
- **菜单项**：
  - 打开搜索（右侧显示快捷键）
  - 偏好设置
  - 暂停索引 / 继续索引（右侧显示 空闲 / 进行中 / 已暂停）
  - 检查更新（右侧显示 已最新 / 发现 x.y.z）
  - 开机启动（右侧显示 已开启 / 已关闭）
  - 打开数据目录
  - 退出 TraceFind
- **交互**：右键贴着托盘图标弹出，自动避开屏幕边缘；点空白、按 Esc 或再次右键收起

## 验证

- 用 Win32 给托盘窗口投递右键消息：面板窗口出现（283×429，WebView 尺寸 268×420）
- 面板内容读取真实状态：`11 个文件`、`Ctrl+Alt+Shift+E8`、`空闲`、`已关闭`
- 发送 Esc 后面板窗口消失
