# TraceFind 2.2.0

「检查更新」后面那一步现在真的能一键完成了：下载、校验、替换、重启。

## 新增

- **下载并安装**：设置 → 关于 → 发现新版本后点一次
  1. 下载官方 zip
  2. 校验 sha256（与发布时上传的一致才会继续）
  3. 解出 `TraceFind.exe`，校验 PE 头与文件大小
  4. 等当前进程退出后替换，并自动重启
- **进度显示**：下载百分比实时更新；替换阶段显示"即将重启"
- **失败保护**：
  - 更新脚本必须先写 `apply.started` 标记，应用才会退出——脚本没起来就不会把自己关掉
  - 替换失败会把 `TraceFind.exe.old` 还原回去
  - 旧版本保留为 `.old`，下次更新时清理
- **只走官方渠道**：只接受本项目 release 地址；没有 sha256 时不提供一键安装，退回「查看下载」

## 限制

- 便携版放在**用户可写目录**（下载、桌面、D 盘自建目录）可直接更新
- 放在 `Program Files` 等受保护目录时需要管理员权限，会更新失败并保留旧版；这种情况请手动下载覆盖
- 只支持 Windows

## 验证

用发布包自身做端到端测试：旧 exe 哈希 `EA8E05D2…` → 更新后 `3EA1E1B1…`，与 zip 内 exe 哈希一致；`apply.log` 记录 `ok`，程序自动重启。

## 升级

直接替换 exe；下次检查到新版本时就能用一键更新。
