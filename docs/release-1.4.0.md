# TraceFind 1.4.0

输入与选中不再互相打架：改词时不会误开旧文件，鼠标划过不会改掉键盘选中，范围与筛选集中在搜索框下面。

## 修复

- **改词后立刻按 Enter 不再打开旧文件**：结果与「查询 + 范围」绑定，新结果到达前列表变淡，打开 / 预览 / 定位都会先提示「结果还在更新」
- **问答面板 Esc 生效**：Esc 顺序为 关问答 → 关预览 → 清空搜索 → 隐藏窗口
- **悬停不再改变键盘选中**：鼠标划过只做浅底反馈，单击选中，双击或 Enter 打开
- **范围移到搜索框下**：`范围：xxx ×` 与类型、排序同一行，零结果时直接给「搜索全部目录」
- **结果行信息固定**：文件大小与修改时间始终显示，快捷键提示只留在底栏；正文摘要去掉 Markdown 标记，保留一行命中上下文

## 顺带

- 语义检索的竞态改为 generation + requestId 双重校验，慢查询回来不会覆盖新结果

## 说明

索引结构与数据格式未变，直接替换 exe。
