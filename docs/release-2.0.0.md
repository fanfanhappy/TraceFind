# TraceFind 2.0.0

大版本：第一次打开不再是一个空列表，而是三步就能跑起来的引导。

## 新增

- **三步引导**：欢迎 → 选要搜的文件夹 → 建立索引
  - 入场动画：logo 缩放 + 文字错峰上浮，`prefers-reduced-motion` / 设置里的「减少动效」会直接关掉动画
  - 目录卡片预选桌面、下载、文档，可一键取消
  - **添加其他文件夹**：调用系统目录选择器，原生体验
- **首启更轻**：第一次只索引文件名（不默认开正文与 OCR），几秒就能搜；之后可在设置里开
- **重看引导**：设置 → 关于 → 重新观看新手引导，不动已有目录与索引
- **引导期间防误触**：背后的结果列表与状态栏不接收点击

## 升级说明

- 老用户不会看到引导（已配置目录即视为完成），行为不变
- 新增运行时依赖 `tauri-plugin-dialog`，仅用于选目录；不会联网

## 验证

隔离配置目录跑完整流程：欢迎 → 选目录 → 建立索引，结束后 `onboardingComplete = true`、索引目录写入、列表出现结果；重放引导后原有目录保留。
