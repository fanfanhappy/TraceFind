# TraceFind 2.9.0

AI 页重排了顺序：**选用途 → 填配置 → 验证并启用**。以前是先改配置、再找开关、再猜能不能用。

## 语义检索

- 顶部固定一行：状态标签 + 说明
  - `未配置`：还差接口地址 / Key / 模型
  - `可启用`：配置齐了，还没验证
  - `正在建立索引` / `正在下载模型`
  - `可搜索`：可搜索，附块数与向量数
  - `出错`：直接给原因
- 本地模式只显示模型下载与索引进度，不出现云端字段
- 云端模式按 **接口地址 → API Key → 嵌入模型** 排列
  - Key 不保存也能点「从接口获取」拉模型列表
  - 模型可下拉选，也可手动输入
  - 「会发送正文片段与查询」写在启用按钮旁边，点之前就能看见

## 验证并启用

主按钮用当前草稿发一次真实嵌入请求：

- 成功才保存（Key 仍走 DPAPI），随后开始建立索引
- 失败只在页面给原因，**保留输入和现有生效配置**
- 更换提供方或嵌入模型时，旧向量会清空并重建，页面会提示

## 索引管理

「重建语义索引」收进折叠区，旁边说明什么时候会自动重建。

## AI 文件问答

独立卡片，和语义检索分开验证、分开显示状态（`未配置 / 可启用 / 可用`）。凭据与语义检索共用；如果只想要问答、语义用本地模型，卡片里直接填接口地址与 Key 即可。

## 实测

- 本地模式：状态 `可启用`，按钮「启用本地模型」→ 调用后 `semanticEnabled=true`
- 云端模式：行顺序 `接口地址 | API Key | 嵌入模型`，缺字段时按钮置灰
- 错误 Key：`验证失败：…401`，配置未被写入
- 问答模型错误 Key：`问答模型验证失败：…401`
