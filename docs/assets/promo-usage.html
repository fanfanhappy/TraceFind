怎么用 TraceFind

四个动作：唤起 → 搜 → 先看 → 直接问

Windows · 单 exe
1
唤起，随手输入
任意界面按 Ctrl + Alt + Space。文件名、拼音首字母、正文关键词都能搜，结果按相关度排。
2
收窄范围
点类型筛选（文档 / 图片 / 代码 / 文件夹），或按目录限定；排序可切相关度、时间、名称、大小。
3
先看，再决定打开
Ctrl + Space 开预览：文档直接读、代码有语法高亮、图片直接看，命中词会高亮。
4
记不住原词？直接问
Ctrl + Shift + Enter：先本地检索资料，再让模型基于这些片段作答，答案带 [n] 引用。
唤醒 Ctrl+Alt+Space 打开 Enter 预览 Ctrl+Space 定位 Ctrl+Enter 问 AI Ctrl+Shift+Enter 隐藏 Esc
