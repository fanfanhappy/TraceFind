# TraceFind 1.2.0

界面收紧版本：在 800×540 的小窗口里，让首屏看得见更多文件、更容易扫读。

## 改动

- **搜索区收紧**：搜索框 64 → 54 px；「搜索结果 / N 项 / 排序」合并进筛选行，首屏可见行数从约 4 行提升到约 6 行
- **结果行固定两列**：图标 + 文件名/摘要 + 固定 148px 的「大小 · 时间」列；操作提示改为浮层，选中时不再把内容挤走
- **强调色收敛**：统一为一套紫，筛选用浅底、选中行用低饱和底、命中词用底色 + 字重，不再三种蓝紫抢注意力
- **预览更像阅读区**：打开/定位移到标题栏，正文独立滚动；文档抽屉 320px、代码 384px；正文行距 1.85
- **标题栏与底栏减噪**：版本号移入「关于」；底栏只保留常用键位与「N 文件 + 实际唤起键」

## 说明

这是纯界面调整，索引、搜索与数据格式均未变化，直接替换 exe 即可。
