# TraceFind 2.5.0

把"第一次出现"和"窗口之间切换"的手感处理干净。

## 改动

- **首帧不闪**：主窗口隐藏创建，主题、材质准备好之后才显示，再播 160 ms 淡入 + 4 px 上移
- **索引统计不挡首帧**：窗口先出来，文件数等数据随后异步填充
- **设置窗复用**：关闭只隐藏不销毁，再次打开无需重新加载页面；已可见时只聚焦；连点「设置」只开一次
- **设置窗也不闪**：隐藏创建 → 套材质 → 再显示
- **返回搜索有衔接**：设置窗先 110 ms 淡出，主窗口显示并等待 170 ms 后设置窗才隐藏；`Esc` 与返回按钮走同一条流程
- **减少动效**：直接切换，不做淡入淡出；相位兜底计时器归零，状态立即收敛

## 验证

- 启动日志顺序：`frontend_ready` → 显示窗口（材质已套好）→ 可交互
- 设置窗 `Esc` 后原生可见性：主窗口 `Visible=True`，设置窗 `Visible=False`
- 重新打开设置：CDP target 未变、页面标记未丢 → 说明没有重新加载
- 减少动效开启：切回搜索 150 ms 内主窗口已处于 visible 相位

索引、更新、数据格式未变。
