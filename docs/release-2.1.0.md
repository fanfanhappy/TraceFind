# TraceFind 2.1.0

加了更新检查：不用每天去仓库看有没有新版本。

## 新增

- **启动时检查**：默认每天最多一次，可在「设置 → 关于 → 启动时自动检查」关掉
- **手动检查**：设置 → 关于 → 检查，显示「已是最新」或「发现新版本 x.y.z」
- **状态栏提示**：有新版本时右下角出现「新版本 x.y.z」，点击打开发布页
- **跳过此版本**：不想升级时点一次，之后不再提示这个版本

## 实现说明

- 只读取 GitHub 的公开版本信息，**不上传任何本地数据**
- 先走 GitHub API；被限流（403/429）时自动改读 `releases/latest` 的跳转地址，不消耗 API 配额
- 打开链接只允许本项目地址，不会变成通用 URL 启动器
- 离线或检查失败时静默处理，只在手动检查时给出原因

## 测试

`TRACEFIND_UPDATE_BASE` 可指向本地 mock（返回 GitHub 形状的 JSON），用于验证提示与设置页逻辑。

## 升级

直接替换 exe。设置文件新增三个字段（`checkUpdates` / `lastUpdateCheck` / `skippedVersion`），老配置自动补默认值。
