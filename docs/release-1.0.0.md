# TraceFind 1.0.0 发布说明

首个正式版本。Windows 本地文件搜索，单 exe、无安装器、无后台账号。

## 能做什么

| 能力 | 说明 |
|---|---|
| 文件名/路径搜索 | 中文、拼音全拼、首字母（`cwbg` → 财务预算报告）、子序列容错 |
| 正文检索 | TXT/MD/代码、DOCX/PPTX/XLSX、PDF、HTML；FTS5 + 中文分词 |
| OCR | 图片与扫描件 PDF 走 Windows 自带 OCR，不占体积（单份 PDF 最多 12 页） |
| 语义检索 | 本地 ONNX（bge-small-zh，按需下载）或云端 Embedding；文件名/正文/语义三路 RRF 融合 |
| 排序与筛选 | 相关度/修改时间/名称/大小；文档/图片/代码/文件夹/其他 |
| 快速预览 | 文本分页（6 万字符/页）、代码语法高亮、命中定位、图片直显 |
| AI 问答 | 检索增强：本地挑 ≤6 段正文 → 云端模型作答，带 [n] 引用；`Ctrl+Enter` 触发 |
| 常驻体验 | 全局快捷键（冲突自动降级）、托盘、开机自启、置顶、材质跟随主题 |

## 性能（本机实测）

| 指标 | 数值 |
|---|---|
| 冷启动到可交互 | 118 ms |
| 唤起（热键 → 可交互） | P50 18 ms / P95 31 ms |
| 搜索（14,596 文件 + 15,599 向量） | P50 27 ms / P95 51 ms |
| 全量扫描 | 0.45 s |
| 正文抽取（1,060 篇） | 约 2 分钟（后台低优先级） |
| exe 体积 | 44.2 MB（无额外 DLL） |
| 模型体积 | 本地语义模型 90.9 MB，按需下载到 `%APPDATA%` |

## 数据与隐私

- 索引库：`%APPDATA%\com.tracefind.desktop\index.db`
- 配置：`%APPDATA%\com.tracefind.desktop\settings.json`
- 日志：`%LOCALAPPDATA%\com.tracefind.desktop\logs\tracefind.log`
- 本地模式下文档与查询**不出网**；云端模式会在设置页明确列出「发送内容 / 目标地址 / 参与目录」，并要求勾选确认
- API Key 用 Windows DPAPI 加密存储，前端永远拿不到密文

## 已知限制

1. **扫描件 PDF 只认前 12 页**，且依赖原图清晰度。
2. **语义检索的准确率受限于小模型**（bge-small-zh），阈值 0.50 偏保守，长文档的段落级召回一般。
3. **AI 问答只支持云端模型（设计决定）**：接入本地大模型会把安装包从 44 MB 推到 GB 级，与"轻量本地搜索"的定位冲突，因此**不列入路线图**。检索与索引仍然全在本地，只有问答这一步走云端。
4. **没有做重排（cross-encoder）**：现有排序是启发式打分 + RRF，尚未引入第二个体积模型。
5. 仅支持 Windows 10/11（依赖 WebView2 与 WinRT OCR）。

## 升级与回退

- 直接替换 exe 即可，索引与配置在 `%APPDATA%` 里，向前兼容
- 语义索引与正文索引都可由设置页一键重建
