# TraceFind 2.3.1

让「下载并安装」在 API 限流时也能出现。

## 修复

- GitHub 匿名 API 每小时只有 60 次，被限流（403）时原先只能拿到版本号、拿不到 sha256，安装按钮因此退化为「查看下载」
- 现在兜底按版本号直接拼出 `.sha256` 资产地址去取哈希（不走 API 配额），校验通过后照常一键安装
- 单测覆盖：从资产地址取 `2.3.0` 的 sha256，与发布值一致

## 关于「查看下载」的说明

如果你看到的是「查看下载」而不是「下载并安装」，通常是这两种情况：

1. **应用版本早于 2.2.0**——一键安装是 2.2.0 才加入的，需要手动更新一次，之后就能一键升级
2. **确实没有可用哈希**（网络异常、资产缺失）——此时保留手动下载更安全

## 升级

直接替换 exe；或从 2.2.0+ 在设置 → 关于点「下载并安装」。
