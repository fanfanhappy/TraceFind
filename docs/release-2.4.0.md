# TraceFind 2.4.0

键盘分工改清楚了：空格归输入，预览在列表里和按钮上。

## 改动

- **搜索框里的空格就是空格**：多词查询直接打「预算 报告」，不再需要 Shift+Space
- **结果列表里空格预览**：方向键或点击进入列表后，按 `Space` 开/关预览
- **`Ctrl+Space` 仍然随时可用**：焦点在搜索框里也能预览，兼容旧习惯
- **行内预览按钮**：每条结果右侧一个眼睛图标，选中或悬停时变亮，鼠标点击即可预览
- **元信息列加宽到 200px**：眼睛按钮、文件大小、修改时间三者完整显示，不再被裁切

## 键盘对照

| 场景 | 按键 |
|---|---|
| 输入多词查询 | `Space` |
| 列表里预览 | `Space` |
| 搜索框里预览 | `Ctrl + Space` |
| 关闭预览 | `Esc` 或再按一次预览键 |

## 说明

底栏提示已改为「Ctrl+Space 预览」，与真实行为一致。索引、更新、数据格式未变。
