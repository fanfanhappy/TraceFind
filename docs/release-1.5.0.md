# TraceFind 1.5.0

图片和扫描件里的文字也能搜到，并且会告诉你「这段内容来自 OCR」——而不是混在普通正文里让你猜。

## 新增

- **OCR 来源标签**：`doc_text` 增加 `via_ocr` 字段，OCR 得到的正文在结果行标「OCR」
- **标签优先级**：语义 > OCR > 正文；文件名本身已命中时不加标签，避免每行都挂标记

## 迁移说明

- 老库启动时自动补列，图片正文按定义回填为 OCR（无需重扫）
- 扫描件 PDF 需要「重建正文索引」后才会带 OCR 标记，其余数据不受影响

## 验证

用一张含中文的图片做端到端验证：搜索只出现在图中的词（如「分两期」），结果行显示 `OCR` 标签，摘要来自图片文字。

索引结构变更只新增一列，数据格式向后兼容，直接替换 exe 即可。
