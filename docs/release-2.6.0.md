# TraceFind 2.6.0

托盘不再只是个"退出"入口。

## 菜单

```
打开搜索（当前快捷键）
偏好设置…
────────────
暂停索引 / 继续索引
检查更新…
────────────
开机启动
打开数据目录
────────────
退出 TraceFind
```

- **左键**：唤起 / 隐藏搜索窗口（保持原行为）
- **右键**：菜单
- **暂停索引**：只在扫描进行或已暂停时可点，暂停后变成「继续索引」
- **检查更新**：直接检查；有新版本会抬出主窗口并在状态栏提示，已最新则回一条状态
- **打开数据目录**：排查问题时直接定位到 `index.db` 所在目录

## 托盘提示

悬停显示实时状态，例如：

```
TraceFind · 11 个文件 · Ctrl+Alt+Shift+F1 唤起
```

文件数在扫描结束后更新（之前因为刷新时机早于统计写入，提示一直停在"尚未建立索引"，这版修了）。图标换成 128px 源图，高 DPI 下更清晰。

## 验证

隔离语料启动后日志：

```
托盘已创建：TraceFind · 尚未建立索引 · Ctrl+Alt+Shift+F1 唤起
索引完成：11 个条目
托盘已刷新：TraceFind · 11 个文件 · Ctrl+Alt+Shift+F1 唤起
```

索引与数据格式未变。
