# 数据与隐私

## 搜索时数据去了哪里

| 功能 | 处理位置 | 发送内容 |
| --- | --- | --- |
| 文件名、拼音、正文与 OCR | 本机 | 文件及查询由本机处理。 |
| 本地语义检索 | 本机 | 首次使用时可能下载模型。文档嵌入与查询推理在本机执行。 |
| 云端嵌入 | 设置中的接口 | 查询文本，以及用于建立向量索引的文档正文片段。 |
| AI 文件助手 | 设置中的问答接口 | 问题、匹配的正文片段、文件名和完整路径。 |

云端嵌入与 AI 文件助手使用配置的接口地址和 API Key。Windows DPAPI 用于保护本地保存的密钥。云端服务的数据保留规则取决于所选服务。

## 已知行为

- 云端嵌入在开启时检查确认状态。运行中的请求和后台批次尚未统一检查授权状态。需要停止使用云端时，请关闭相关功能并退出 TraceFind。
- **更新检查**是唯一会主动联网的功能之一：开启时向 GitHub 请求公开的版本信息（API 或 `releases/latest` 跳转），不发送任何本地文件、路径或标识；关闭后完全离线。
- **更新安装**（你主动点击时）会从 GitHub 下载官方 zip，并用发布时上传的 sha256 校验；不上传任何本地数据，也不会把文件发到别处。装在当前用户目录时可以直接替换程序；装在受保护目录（如 `C:\Program Files`）时需要管理员权限，请改用新安装包覆盖安装。
- AI 文件助手会把完整文件路径放入问答上下文。快捷键为 `Ctrl + Shift + Enter`（`Ctrl + Enter` 仍是「在资源管理器中定位」）。
- 索引库会保存文件路径、可检索正文及向量。诊断日志可能记录路径或查询。分享数据库或日志前，请检查其中的内容。

## 本地文件位置

| 数据 | 默认位置 |
| --- | --- |
| 配置 | `%APPDATA%\com.tracefind.desktop\settings.json` |
| 索引 | `%APPDATA%\com.tracefind.desktop\index.db` |
| 模型缓存 | `%APPDATA%\com.tracefind.desktop\models\` |
| 诊断日志 | `%LOCALAPPDATA%\com.tracefind.desktop\logs\` |

从 TraceFind 迁移的条件见 [迁移说明](migrating.md)。
