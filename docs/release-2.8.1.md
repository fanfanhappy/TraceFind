# TraceFind 2.8.1

托盘面板的几个反馈问题。

## 修复

- **检查更新不再"点了就消失"**：点击后右侧显示「检查中…」，完成后显示「已最新」或「发现 x.y.z」，面板保持打开
- **快捷键显示实际生效值**：之前读的是设置里的配置值，快捷键被占用降级时显示会不准；现在读运行时状态
- **开机启动切换后保留面板**：右侧「已开启 / 已关闭」立刻更新，不用重新打开

## 验证

隔离实例打开面板 → 点「检查更新」→ 4 秒后右侧变为「已最新」，面板仍在；`打开搜索` 右侧显示实际生效的 `Ctrl+Alt+Space`。

## 升级

「下载并安装」现在走资产直链（2.8.0 已修）；从 2.4.0–2.7.0 升级仍需手动一次。
