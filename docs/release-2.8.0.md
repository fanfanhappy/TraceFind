# TraceFind 2.8.0

修一个会让「下载并安装」必然失败的问题。

## 问题

2.4.0 起的一键更新把**发布页地址**当成了安装包地址，下载到的是 HTML 页面，sha256 自然对不上，界面就会显示"校验失败"。截图里 `d604e27e…` 那个哈希，就是网页本身的哈希。

## 修复

- 更新信息里新增 **zip 资产直链**（`/releases/download/.../TraceFind-x.y.z-win64.zip`），安装只走这个地址
- 地址校验收紧为只接受 `releases/download/` 前缀
- 下载后先看前 4 字节是不是 `PK`（zip 魔数），不是就直接报"下载到的不是安装包"
- API 被限流时，兜底也按版本号拼出资产直链

## 升级方式（重要）

**2.4.0 – 2.7.0 的「下载并安装」按钮本身就是坏的**，请用「查看下载」手动下载 2.8.0 并替换 exe 一次。从 2.8.0 起，一键更新可以正常使用。

## 验证

用 2.7.0 的发布页做端到端测试：

```
assetUrl: .../releases/download/v2.7.0/TraceFind-2.7.0-win64.zip
install:  scheduled
apply.log: ok
更新后 exe 哈希 = 发布包内 exe 哈希（E7A2A487…）
```

索引与数据格式未变。
