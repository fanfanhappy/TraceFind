# TraceFind 1.1.1

修复版本：让 AI 问答真正可用，并修掉三处检索/呈现问题。功能与 1.1.0 相同。

## 修复

| 问题 | 说明 |
|---|---|
| 问答快捷键无效 | `Ctrl+Enter` 一直属于「在资源管理器中定位」，问答改为 **`Ctrl+Shift+Enter`** |
| 口语化提问搜不到资料 | 整句进 FTS 匹配不到；改为拆成中文二元组 + 英文整词逐个召回再合并 |
| 答案排版 | 渲染 `**粗体**`、行内代码与列表；问答时隐藏结果表头与类型筛选 |
| 最近列表忽略类型筛选 | 空查询下的「最近使用」现在也会按「文档/图片/代码…」过滤 |

## 升级

直接替换 `TraceFind.exe`，数据目录与索引结构未变。
